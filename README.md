# Учебный проект: Менеджер паролей (Password Manager)

Программа для безопасного хранения учетных данных (логинов, паролей, ссылок) в зашифрованном локальном хранилище. Разработано в рамках учебного группового проекта.

## Состав команды и роли
*   **Черепанов М. (Тимлид / Архитектор)** — настройка архитектуры решения (Solution), разработка криптографического модуля (AES-256), проведение код-ревью.
*   **Балобанов Б. (UI/UX Разработчик)** — проектирование и верстка интерфейса на Windows Forms, настройка навигации между окнами.
*   **Кутявин Д. (Разработчик БД)** — проектирование схемы данных, создание локальной БД Microsoft Access, реализация логики взаимодействия с БД (CRUD-операции через OLE DB).
*   **Широких Д. (Тестировщик / копирайтор)** — написание Unit-тестов для проверки логики шифрования и генерации паролей, валидация полей ввода.

## Технологический стек
*   **Язык программирования:** C# (.NET Framework 4.8 / .NET 8)
*   **Интерфейс:** Windows Forms (WinForms)
*   **Шифрование:** AES-256 (встроенные средства `System.Security.Cryptography`)
*   **База данных:** Microsoft Access (`.accdb`)
*   **Технология доступа к данным:** `System.Data.OleDb` (драйвер Microsoft ACE OLEDB 12.0)

## Инструкция по запуску
1. Склонируйте репозиторий: `git clone <https://github.com/X1nQ2/PasswordManager-WinForms>`
2. Открывайте файл решения `PasswordManager.sln` через Visual Studio.
3. Убедитесь, что в верхней панели Visual Studio в качестве платформы сборки выбрана **x64** (или **x86**).
4. Нажмите `F5` (или кнопку "Пуск") для сборки и запуска приложения.
5. Файл базы данных `PasswordManagerDB.accdb` автоматически скопируется в выходную директорию (`bin/Debug`) при первой сборке.
